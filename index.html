数据库配置说明

本系统在 Supabase 中使用以下 5 张表。codes、clean 为旧表（已存在）；duty_members、duty_records、penalty_members 为值日模块新建表。字段名必须与下表完全一致。

duty_members（值日成员表）

id — int8，主键，自增
name — text，唯一，值日生姓名

duty_records（值日记录表）

id — int8，主键，自增
date — text，日期，格式 2026-11-22
members — text，当日人员（JSON 数组文本）
start_index — int8 / int4，默认 0，下一轮起始位次

penalty_members（罚扫地备忘录表）

id — int8，主键，自增
name — text，唯一，姓名
days — int4，剩余罚扫地天数

codes（兑换码表 · 已有）

id — int8，主键；code — text；reward — text；used — boolean；use_time — text

clean（免扫地人员表 · 已有）

id — int8，主键；name — text，唯一
① 一键建表（Supabase → SQL Editor 粘贴运行）

                

                
                
② 安全策略（开启 RLS 后，允许网页读写；USING / WITH CHECK 均为 true）

                

                

                

                
提示：若你的 codes、clean 旧表是关闭 RLS 使用的，新表也可直接关闭 RLS；开启 RLS 则必须配置上面的策略，否则网页读不到数据。
